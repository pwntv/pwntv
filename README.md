# PwnTV

**Own your TV.**

PwnTV is an open-source, gamepad-first home theater platform that brings your
streaming services, games, and browser into a single living-room-friendly
interface — no vendor lock-in, no walled garden.

## Why

Smart TVs and streaming boxes bury the things you actually want behind ads,
recommendation algorithms, and inconsistent remotes. PwnTV aims to be a
single, fast, controller-driven front end that launches the services and
games you already use, without getting in the way.

## Status

> **Early development — not usable yet.**
>
> PwnTV is in the walking-skeleton stage. There is no installable build and
> no working dashboard yet. Watch the repo or check the roadmap below for
> progress.

## Planned features

- Gamepad-first dashboard for navigating without a keyboard or mouse
- Unified launcher for streaming and gaming services, including:
  - YouTube
  - Spotify
  - Steam
  - A general-purpose web browser
  - Netflix
  - HBO Max
  - Prime Video
  - Stremio
  - Game launchers (e.g. other storefronts and emulator front ends)

None of the above is implemented yet — this list describes the intended
scope, not current functionality.
